## About

ReSnake is my reinterpretation of the classic Snake game, built with Java Swing.

## Features

- Two-player mode
- Custom snake colors
- Play against a bot
  - Normal difficulty
  - Hard difficulty

## Controls

| Player | Controls |
| :---: | :--- |
| Player 1 | `W`, `A`, `S`, `D` |
| Player 2 | Arrow keys |

## How to play

1. Download the ZIP from **Releases**.
2. Extract the folder.
3. Run `ReSnake.exe`.

## Built with

- Java
- Java Swing
